# Campo Minado

Jogo de campo minado desenvolvido em Java utilizando Swing para interface gráfica

## Funcionalidades

- Tabuleiro com geração aleatória de minas
- Diferentes níveis de dificuldade
- Marcação de possíveis minas
- Abertura automática de células vazias
- Verificação de vitória e derrota
- Interface inspirada no Campo Minado clássico

## Tecnologias utilizadas

- Java 21
- Java Swing

## Como executar

### Pelo executável

Baixe a versão disponível em:

Releases → CampoMinado.zip

Extraia os arquivos e execute:

```text
CampoMinado.exe
```

### Pelo projeto

Execute a classe:

```text
CampoMinado.java
```
